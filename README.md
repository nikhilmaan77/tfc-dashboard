# The Fresh Connection — SBR 2 Dashboard

Interactive dashboard for **Team: Not Fast, Just Furious**, GMBA October 26, covering Rounds 1–3 of The Fresh Connection supply chain simulation.

**Live:** `https://<your-username>.github.io/tfc-dashboard/`

## What this is

A single self-contained HTML file. No build step, no dependencies, no internet required once loaded. Open `index.html` in any browser and it works.

## Presenting

Press keys **1–9** to jump straight to any section:

| Key | Section |
|---|---|
| 1 | Overview and headline KPIs |
| 2 | Supply chain strategy |
| 3 | ROI trajectory |
| 4 | The promise gap |
| 5 | Round-by-round decisions |
| 6 | How the turnaround happened |
| 7 | Function drill-down |
| 8 | KPIs achieved and missed |
| 9 | Rounds 4 to 6 |

The nav bar at the top also works as click-through links and highlights the current section as you scroll.
